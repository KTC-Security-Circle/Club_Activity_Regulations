# サークル活動規約第四版(仮)

# 第１条　目的

セキュリティサークル（以下「本サークル」という）は、京都デザイン＆テクノロジー専門学校（以下「本校」という）を拠点として活動し、知識の向上、イベント参加の拠点、他学年・姉妹校との交流等を目的とする。

知識を取り入れ、それをアウトプットする場として、知識の定着と実践ができる環境を提供する。

本サークルの名にある「セキュリティ」は、すべての物事に関わっている。このことを念頭に置いて活動できるようになることを目指す。

げんきにがんばろーってこと。

# 第２条　運営

## 1．役職

本サークルの運営にあたり、以下の役職を設ける。

- 代表：本サークルを代表し、活動全般を統括する。
- 副代表：代表を補佐し、その職務の一部を代行する。また、後任の代表を選出する（第２条3参照）。
- 書記：会議の議事録の作成、メンバーの管理などを行う。
- 管理者：本サークルで利用するサービスのそれぞれの管理を担当する。人数は状況に応じて調整する。

このうち、代表・副代表・書記の３名に加えて管理者を、本校に報告する役職とする。

## 2．役員の任命

- 役員の任命は、年度末に行う。
- 副代表は、卒業年度（最終学年）の学生が務める。卒業年度の学生が複数いる場合は、全員が副代表となる。
- 代表は、卒業年度に達していない学生（四年制学生は三年次まで、三年制学生は二年次まで）の中から、副代表が決定する。副代表が複数いる場合は、その協議により決定する。
- ただし、副代表となる卒業年度の学生が存在しない場合（発足初年度を含む）は、その時点のメンバーの互選により代表を選出する。
- 書記および管理者は、代表と副代表が協議のうえ、本サークルに所属する学生の中から選ぶ。

## 3．役員の任期

- 役員の任期は、本校の定める年度開始から年度末までとする。
- 後任の役員が決定し、引き継ぎが完了した時点で現役員の任期を終了する。年度末の任命から新年度開始までの間も、引き継ぎが完了するまでは現役員が職務を継続する。

## 4．役員の解任

- 役員が本サークルの名誉を著しく傷つけた場合、または役員としての適格性を欠くと判断される場合は、役員全体でミーティングを行い、解任を審議する。
- ミーティングには該当役員も出席し、弁明の機会を与える。ただし、該当役員は当該解任の議決には加わらない。
- 解任は、該当役員を除く役員の過半数の同意をもって決定する。

## 5．役員の辞任

- 役員の自発的な辞任（役職を降りること）は、代表が許可する場合を除き、認めない。
- 代表自身が辞任する場合は、副代表および他の役員の過半数の同意を得るものとする。

## 6．役員の欠員

- 役員に欠員が生じた場合は、速やかに後任を補充する。補充された役員の任期は、前任者の残任期間とする。

# 第３条　活動場所

活動場所に特段の定めはない。本校の内外を問わず、メンバーで集まって活動してよい。ただし、外部に情報を漏洩することのないよう特に注意すること。

ミーティングの時間・場所などは、プロジェクトごとに自由に決定すること。

# 第４条　活動内容

本サークルで行っている活動を以下に記す。

- 産学連携プロジェクトへの参加
- 学内・学外で開催される体験授業の企画・運営

# 第５条　利用サービス

本サークルで利用しているサービスを以下に記す。

- MS Teams
- Discord
- Notion
- GitHub

これらのサービスを使用するためのアカウントを、あらかじめ準備しておくこと。

# 第６条　行動規範

## 1．連絡・参加

- 本サークルの活動を欠席・遅刻する場合は、活動開始時刻までに、代表・副代表またはプロジェクトのリーダーが確認できるチャットツールに連絡を入れること。
- 活動内で利用するサイトでアカウント登録が必要な場合は、原則として学校用アドレスを使用すること。ただし、既に個人アドレスでアカウントを所有している場合はこの限りでない。

## 2．プロジェクトに対する責任

- 関わるプロジェクトを途中で投げ出さないこと。筋を通し、連携先の企業に迷惑をかけないよう努めること。

## 3．倫理・法令の順守

- 本サークルで得た知識を、悪用または犯罪行為に利用することを禁止する。
- 不正アクセス禁止法、個人情報保護法その他の関連法令を順守すること。
- 自身が明示的に許可を得た対象以外に対して、テスト・調査・攻撃等の行為を行わないこと。
- 連携先との秘密保持契約（NDA）および取り決めを順守し、業務上知り得た機密情報を外部に漏らさないこと。なお、何が機密情報に当たるかは、プロジェクトごとに確認すること。
- いかなる場合でも、他人が不快に感じる行為は慎むこと。

## 4．多様性への配慮

- サークル活動が、パートナー（昨今の多様性への合理的配慮および諸般の事情による表記）との用事と重なる場合に限り、特例としてサークル活動への参加を強制しないものとする。ただし、参加の可否は双方が納得のうえで決定すること。

# 第７条　入会・退会

## 1．入会

- 本校に在籍する学生で、本サークルの目的に賛同する者は、代表または副代表に申し出ることで入会できる。入会の承認は代表または副代表が行う。
- 入会にあたっては、第５条に定める利用サービスのアカウントをあらかじめ準備すること。

## 2．退会

- メンバーは本サークルを退会することができる。退会する場合は、代表に申し出ること。
- 関わっているプロジェクトがある場合は、連携先に迷惑がかからないよう、引き継ぎを完了させてから退会すること。

# 第８条　規約の改正

- この規約の改正は、役員の過半数の同意をもって行う。
- 改正を行った場合は、改正の内容・日付・改正者を「更新履歴」に記録すること。
