サークル活動規約第三版

第１条　目的

セキュリティサークル（以下 本サークルという）は、京都デザイン＆テクノロジー専門学校（以下 本校）を拠点として活動し、知識の向上、イベント参加の拠点、他学年、姉妹校との交流等を目的とする。

知識を取り入れ、それをアウトプットする場として、知識の定着、実践できる環境を提供する。

本サークルの名にある、セキュリティはすべての物事に関わっている。このことを念頭に置いて活動ができるようになる。

げんきにがんばろーってこと。

第２条　運営

  1. 役職

    本サークルの運営にあたり以下のとおり役職を設ける

    1. 代表：本サークルを代表し、活動全般を統括する。
    2. 副代表：代表を補佐し、一部その職務を代行する。
    3. 書記：会議の議事録の作成、メンバーの管理などを行う。

    学校に報告する役職として上記３名に加えて、以下の役職をゆるーく決定する

    管理者：本サークルで利用するサービスのそれぞれの管理を担当する。状況に応じて人数は調整する。

  2. 役員の任命

    • 役員の任命は、年度末に行うこととする。
    • 本サークル代表（以下 代表）は、本サークル福代表（以下 副代表）が決定することとする。 ただし、卒業年度生は代表になれないもの（四年制学生であれば三年次まで、三年制学生であれば二年次まで）とし、卒業年度は副代表として活動するものとする。
    • 書記、総務は、代表と副代表で協議し、本サークルに所属している学生から選ぶものとする。
  3. 役員の任期
    • 役員の任期はそれぞれ本校の定める年度開始から年度末までとし、後任の役員の決定をもって現役員の任期を終了する。
  4. 役員の解任および欠員
    • 役員が本サークルの名誉を著しく傷つけた場合、または役員としての適格性を欠くと判断される場合は、該当役員を含めた役員全体でミーティングを行い、その過半数の同意をもってこれを解任できることとする。
    • 役員に欠員が生じた場合は、速やかに後継を補充するものとする。ただし、補充された役員の任期は、前任者の在任期間とする。

第３条　活動場所

活動場所は特段の定めはない。本校の内外問わず、メンバーで集まって活動をしてよいものとする。 ただし、外部に情報を漏洩することのないよう特にすること。

ミーティングの時間、場所などは、プロジェクト毎にそれぞれ自由に決定すること。

第４条　活動内容

本サークルで行っている活動について下記に記す。

  • 産学連携プロジェクトの参加
  • 学内・学外で開催される体験授業の企画・運営

第５条　利用サービス

本サークルで利用しているサービスを下記に記す。

  • MS Teams
  • Discord
  • Notion
  • Github

これらのサービスを使用するためのアカウントをあらかじめ準備しておくこと。

第６条　その他活動にあたって

本サークル活動を欠席する、遅刻する場合は活動開始時刻までに代表、副代表、もしくはプロジェクトのリーダーが確認できるチャットツールに連絡を入れること。

本サークル活動内で利用するサイトにてアカウント登録が必要な場合は学校用アドレスを使用して登録を行うこととする。但し、既に個人アドレスでアカウントを所有している場合、この限りでない。

本サークル内で関わるプロジェクトにおいて、途中で投げ出すことは絶対に無いように努めること。筋を通し、連携先の企業に迷惑をかけることがないように努めること。

本サークルで得た知識の悪用、犯罪行為への利用を禁止とする。 如何なる場合でも他人が不快に感じる行為は慎むこと。

サークル活動にあたり、パートナー（昨今の多様性に対する合理的配慮、また諸般の事情による表記）との用事と重なっている場合に限り、特例としてサークル活動への参加を強制できないものとする。ただし、双方納得の上で参加の可否を決定すること。
